thieponline-guests-mcp

MCP server để AI agent quản lý khách mời trên thieponline.app — liệt kê, thêm, sửa, xóa khách và xuất CSV. Backend Supabase; server tự refresh access token.

⭐ GitHub repo 📖 README đầy đủ

RSVP lưu ở bảng riêng, chỉ khách tự điền qua trang công khai — server này không ghi RSVP.

Cài đặt (MCP client)

Thêm vào cấu hình MCP (mcp.json / claude_desktop_config.json / .kiro/settings/mcp.json):

{
  "mcpServers": {
    "thieponline-guests": {
      "command": "uvx",
      "args": [
        "--from",
        "git+https://github.com/ngoctp27/thieponline-app-mcp",
        "thieponline-guests-mcp"
      ],
      "env": {
        "THIEPONLINE_INVITATION_ID": "<id-thiệp-của-bạn>",
        "THIEPONLINE_REFRESH_TOKEN": "<refresh-token-của-bạn>"
      }
    }
  }
}

Cần uv (uvx) cài sẵn. uvx tự tải package + dependency khi chạy.

Lấy 2 giá trị cấu hình

Đăng nhập thieponline.app, mở trang /guests, mở DevTools (F12).

THIEPONLINE_INVITATION_ID

DevTools → Application → Local Storage → https://thieponline.app → key lastActiveInvitationId → copy value.

THIEPONLINE_REFRESH_TOKEN

Trong Cookies, ghép 2 cookie sb-dudcjocrigjgnprdkijw-auth-token.0 + .1, bỏ tiền tố base64-, decode base64 ra JSON, lấy field refresh_token:

python3 - <<'PY'
import base64, json
p0 = "base64-...phần .0 (bỏ 'base64-')..."
p1 = "...phần .1..."
raw = p0.replace("base64-", "") + p1
print(json.loads(base64.urlsafe_b64decode(raw + "=" * (-len(raw) % 4)))["refresh_token"])
PY
Token xoay vòng: Supabase refresh token dùng 1 lần rồi đổi. Đóng hết tab thieponline.app trước khi copy token cho MCP. Server lưu token xoay vòng vào ~/.thieponline-guests-mcp/token.json nên tự duy trì sau lần seed đầu.

Bảo mật

  • refresh_token là bí mật cá nhân — giữ trong env của MCP client, không commit.
  • Repo không chứa token của ai. Anon key nhúng sẵn là khóa publishable công khai, không phải secret.
  • Token chỉ truy cập dữ liệu của chính tài khoản đăng nhập (RLS).
